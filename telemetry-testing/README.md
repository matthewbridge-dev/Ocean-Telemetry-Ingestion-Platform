# Telemetry Testbed & API Benchmarks

Testing suite to validate oceanographic data sources (NOAA RTOFS S3, Copernicus Marine, HYCOM TDS, NASA ECCO).

## Setup Instructions for Team Members

1. **Prerequisites:**
   - Anaconda or Miniforge installed.
2. **Build Environment:**
   ```bash
   conda env create -f telemetry-testing/environment.yml
   conda activate ocean-testbed
   ```
